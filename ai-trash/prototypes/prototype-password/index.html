Password Prototype

A minimal PWA with a login form the browser recognizes as such: proper autocomplete attributes, a real form submit, and an explicit call to the Credential Management API so the browser offers to save the username and password.

Fill in a username and password, then submit. The browser should offer to save the credentials (or auto-fill if you have already saved them).

Password managers see autocomplete="new-password" and offer to suggest a strong password. On successful submit, the browser is asked to store the new credential.
