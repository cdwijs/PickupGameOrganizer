Encrypted Userdata Prototype

Interactive walkthrough of password-derived envelope encryption. Each step has its own Calculate button and shows its intermediate value. All fields are editable and autosaved to localStorage; they reload on refresh.

Loading Argon2id engine…

Account creation

1. Master password

password (UTF-8 string)

2. Salt

salt = random(16) (hex)

3. KEK — Key Encryption Key

KEK = Argon2id(password, salt) (32 bytes, hex)

4. DEK — Data Encryption Key

DEK = random(32) (hex)

5. wrapped_DEK

wrapped_DEK = AES-GCM(KEK, DEK) (nonce ‖ ciphertext ‖ tag, hex)

6. blob

blob = AES-GCM(DEK, plaintext) (nonce ‖ ciphertext ‖ tag, hex)

Server storage — { salt, wrapped_DEK, blob }

These are the only three items the server keeps. No password, no KEK, no DEK. Pushing populates the decryption section below; you can also edit the fields directly to simulate a tampered or wrong-user record.

Decryption (login)

D0. Fetched from server

fetch(salt, wrapped_DEK, blob)

D1. Entered password

entered_password (UTF-8 string)

Change a single character to see the decryption fail at step D3 with an authentication error.

D2. KEK

KEK = Argon2id(entered_password, salt)

D3. DEK (unwrap)

DEK = AES-GCM-decrypt(KEK, wrapped_DEK) — fails if password is wrong

D4. Plaintext

data = AES-GCM-decrypt(DEK, blob)
